# Phase 6 — XP Catcher integration

This package contains the existing project plus the new XP Catcher mini-game. The source ZIP originally included `.git` and `node_modules`; these are intentionally omitted from this handoff.

## Safest integration into your existing Git repository
1. **Back up** your existing `VELOOP-LevelUp-GitHub` folder.
2. Extract this ZIP to a separate location.
3. Copy the extracted project's `src` folder into your existing project, allowing file replacement. Copy `README.md` if you want the updated phase tracker. Do **not** replace your existing `.git` folder.
4. Open your existing project in VS Code and run `npm install` (if needed), `npm run dev`, and `npm run build`.
5. Open the dashboard, click **XP Catcher** under **Earn More**, and verify Start → Catch → Result → Play Again → Dashboard.
6. After verifying, commit and push changes.

## Demo only
Game rewards are illustrative. No wallet or XP backend updates occur.
