# VELOOP Level-Up Dashboard

A fresh responsive VELOOP Rewards dashboard redesign built with React and Vite.

## Progress
- Phase 1: Preparation & discovery — complete
- Phase 2: React + Vite setup — complete
- Phase 3: UI foundation & design system — complete

## Stack
React, Vite, Bootstrap utilities, CSS Modules, Lucide React.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The assignment PDF is the design source. The existing dashboard is not used as a design reference. Any XP and reward values shown are illustrative demo data only.
